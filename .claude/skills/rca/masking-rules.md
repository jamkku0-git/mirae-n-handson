# RCA 리포트 마스킹 규칙

리포트(`docs/rca/<시나리오>.md`)를 저장하기 전에 아래 규칙을 모두 적용한다. 원본 로그는 바꾸지 않는다.

| 종류 | 대상 | 바꾸는 방법 |
|---|---|---|
| IP 주소 | IPv4 · IPv6, `host:port` 의 호스트 부분 | 구분이 필요하면 역할 별칭(아래), 필요 없으면 `<IP>` |
| 이메일 | `xxx@yyy` 형식 전부 | `<EMAIL>` |
| 학생 식별자 | `STU-…`, 학생 이름 | 구분이 필요하면 `학생A` · `학생B` …, 필요 없으면 `<STUDENT>` |
| 토큰 | Bearer · JWT · 세션 ID · API 키 | `<TOKEN>` |
| 비밀번호 · 접속 문자열 | `password=` · `pwd=` 값, `user:pass@host` 형식의 JDBC · DB URL | `<SECRET>` (호스트는 IP 규칙을 따른다) |

## 역할 별칭

- 가설 · 타임라인에서 어느 서버 · 단말인지 구분해야 하면 IP 를 역할 별칭으로 바꾼다.
  - 업스트림 앱 서버: `API-1`, `API-2` …
  - 교사 화면 클라이언트: `교사단말A`, `교사단말B` …
  - 학생 클라이언트: `학생단말A` …, DB 서버: `DB-1` …
- 같은 원본 값은 리포트 전체에서 같은 별칭으로 바꾼다. 별칭은 처음 나온 순서대로 A, B, C … 를 붙인다.
- 집계 출력 · 발췌 · 명령 예시 안의 값도 같은 별칭을 쓴다.
- 원본 ↔ 별칭 대응표는 파일로 남기지 않는다. 작업 중에만 쓴다.

## 적용 기록

리포트 끝에 종류별 건수를 한 줄로 적는다(0건도 적는다).

```
마스킹 적용: IP 주소 N건 · 이메일 N건 · 학생 식별자 N건 · 토큰 N건 · 비밀번호 · 접속 문자열 N건 (IP 는 역할 별칭 … 로 바꿨다)
```

## 저장 전 확인

`docs/rca/<시나리오>.md` 에 아래 명령을 실행해 결과가 0줄이어야 저장을 마친다.

```bash
grep -nE '([0-9]{1,3}\.){3}[0-9]{1,3}|[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Za-z]{2,}|STU-[0-9A-Za-z]+|Bearer [A-Za-z0-9._-]+|eyJ[A-Za-z0-9_-]+\.|password=[^< ]' docs/rca/<시나리오>.md
```
